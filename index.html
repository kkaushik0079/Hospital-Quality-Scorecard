About this project

Built by Kritika Kaushik as a portfolio project. All hospitals and values are synthetic, generated by scripts/generate_data.py. Measure definitions are modeled on public CMS programs: the Hospital Readmissions Reduction Program (AMI, HF, PN, COPD), HCAHPS overall hospital rating, OP-18b median time from ED arrival to departure, SEP-1 severe sepsis bundle compliance, and the NHSN CLABSI standardized infection ratio (SIR). Goals are illustrative system targets, not CMS benchmarks.

The SQL in sql/ computes the same measures from the raw CSVs, so the dashboard can be reproduced in any warehouse (Snowflake, Postgres, SQLite).

Data as of October 31, 2026 · Synthetic dataset, not real patient or hospital data.
